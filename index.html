📖 系统概述

本系统是一套完整的题库管理与刷题考试工具，支持自定义题库、分题型/分类刷题、模拟考试、错题重练、数据统计、全量备份等功能。 所有数据保存在浏览器本地数据库（IndexedDB），无需服务器，打开即用。

📝 刷题模块

第1步：选择分类：在刷题配置面板中，通过下拉框选择「全部」或具体分类（分类在导入题库时自动识别）。

第2步：筛选条件：可按题型（单选/多选/判断）和状态（全部/未做过/错题集/已掌握）过滤题目。

第3步：开始刷题：点击对应分类或选择后自动开始。左侧显示题号导航窗格，右侧显示题目和选项。

两种模式：刷题模式 点击选项提交答案，查看对错和解析。背题模式 直接展示答案和解析。

单选题/判断题：点击选项自动提交（300ms延时），立即显示结果。

多选题：点击多个选项后，点「确认答案」按钮提交。

答对：显示绿色 ✅，500ms 后自动跳下一题。

答错：显示红色 ❌ 和正确答案，题目加入错题集。需手动点「下一题」。

题号窗格：🟢 绿色=答对，🔴 红色=答错，⬜ 灰色=未做。点击题号可快速跳转。

前进后退：查看已做题时自动显示对错结果和解析，已做题不可重复提交。

进度保存：提交答案时自动保存进度，关闭浏览器后恢复从下一未做题开始。刷题选项记录也会保留。

自定义分类刷题：在题库管理页勾选题目后点「创建分类刷题」，将选中题目组成临时分类。

错题测试：在配置面板中点「错题测试」可专门练习错题集中的题目，答对自动移除。

重新开始：重置当前所有题目的刷题统计（practice_count / in_wrongbook 归零），回到第一题。

重置此分类进度：仅重置当前分类题目的统计（选择具体分类时显示此按钮）。

🧪 模拟考试模块

配置考试：设置考试名称、答题时间（分钟）、及格分数。选择包含的题型和分类（支持按比例分配）。

附加选项：交卷后显示答案、选项乱序（防作弊）、优先抽错题、优先抽未做题。

考试界面：顶部显示倒计时，左侧题号导航，右侧答题区。底部上一题/下一题/交卷按钮。

计时规则：时间用尽自动交卷。切换 Tab 不影响计时（正式考试不可暂停）。

交卷：确认后计算分数、统计对错，生成考试记录。交卷后不可修改答案。

查看答卷：在统计页点击「查看答卷」可逐题回顾，查看每题的对错和正确答案。

导出 Word：点击「📥 导出Word」将考试记录导出为纯净试卷（.doc），只含题目和选项，正确答案用绿色字体标记。不含作答痕迹和解析，可直接打印使用。

恢复考试：如中途关闭浏览器，重新进入考试 Tab 会提示是否继续之前的考试。

📊 统计模块

考试历史：列出所有考试记录，显示名称、时间、题数、对错数、分数、是否及格。支持删除和导出。

分类正确率：按题目分类统计正确率柱状图（绿≥60%，黄＜60%）。

题型正确率：按单选/多选/判断统计正确率。

抽选排行：统计各题目被考试抽中的次数（Top 20）。

⚙️ 题库管理模块

Excel 导入：支持 .xlsx / .xls 格式。表头需包含：题型（单选/多选/判断）、分类、题干、选项A~H、答案、解析（可选）。

Excel 导出：将当前题库导出为 Excel 文件，含所有字段。

手动添加题目：填写类型、分类、题干、选项（至少2个）、正确答案、解析。判断题答案自动转换为 A/B 格式。

答案格式：单向选择填字母如 A，多选填字母连写如 ABC 或 A,B,C（逗号自动去除）。判断题提交时自动转 A（对）/ B（错）。

编辑/删除：点击题目行右侧按钮编辑或删除。支持多选批量删除。

自定义收藏集：勾选题目创建收藏集，在刷题页通过分类下拉选择。删除收藏集不删除题目。

搜索和筛选：支持按关键词搜索题干，按题型下拉筛选。

🎨 显示与字号

顶部右侧按钮：网页/平板可见两个快捷按钮。手机端通过侧滑菜单(☰)中操作。

🌙 显示模式：关(默认白) → ☀️ 护眼(浅绿柔光) → 🌑 夜间(iOS暗黑风格) → 循环切换。

Aᴬ 字号大小：中(默认) → 大(1.15×) → 超大(1.3×) → 小(0.85×) → 循环切换。

夜间模式配色：纯黑底色 #000，卡片 #1c1c1e，分隔线半透白，iOS 风格层次分明。

状态记忆：显示模式和字号选择均自动保存，刷新页面保持设置。

💾 数据管理

存储位置：所有数据（题库、考试记录、收藏集、设置）保存在浏览器 IndexedDB 中，不清除浏览器数据则永久保留。

全量备份：首页「💾 导出全部数据」将全部数据导出为一个 JSON 文件，包含题库、记录、收藏集、设置。

数据恢复：「📥 导入全部数据」选择备份文件导入。采用合并模式：已有数据保留，重复 ID 被覆盖。

重置刷题进度：清空所有题目的刷题统计（答题次数、对错数、错题标记），不删除题目和考试记录。

重置题库统计：清空考试抽选次数和对错记录。

清空全部数据：⚠️ 删除所有数据，需输入确认文字才执行。
